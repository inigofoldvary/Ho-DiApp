# Ho-DiApp (prototipo)

App web (pensada para el móvil) para apuntar quién ha pagado cada cosa de un hogar
compartido, confirmado por los implicados.

- `supabase/01_estructura.sql`: tablas, reglas y permisos. Se pega en Supabase > SQL Editor.
- `src/app`: las pantallas.
- Claves: copia `.env.example` como `.env.local` y pon la URL y la clave pública de Supabase.

Arrancar en local: `npm install` y `npm run dev`.
